# منصّة الأسهم وتوزيعات الأرباح الإماراتية 🇦🇪

منصّة ويب عربية (واجهة من اليمين إلى اليسار) لمتابعة أسهم الشركات المدرجة في **سوق دبي المالي (DFM)** و**سوق أبوظبي للأوراق المالية (ADX)**، مع التركيز على **توزيعات الأرباح النقدية** وتخطيط دخل المحفظة.

> ⚠️ **تنويه:** منصّة معلوماتية للمتابعة فقط — لا تتضمّن أي توصية بشراء أو بيع. بعض القيم
> (الأسعار التاريخية، حركة اليوم، الأحجام، وتنبيهات «العرض التجريبي») مُولّدة خوارزمياً للعرض
> فقط وليست بيانات سوق حقيقية لحظية. تأكّد دائماً من المصادر الرسمية: DFM / ADX / إفصاحات الشركات.

## المزايا

- **📊 نظرة عامة** — مؤشرا السوقين العامّان (DFMGI / FADGI) بقيم حقيقية من التحديث اليومي، نشاط الأسهم المغطّاة واتساع السوق (مرتفعة/منخفضة)، رسم بياني تفاعلي للأسعار، حركة السوق (المرتفعة/المنخفضة/النشطة)، خريطة حرارية حسب العائد/مكرر الربحية/القيمة السوقية، ومتتبّع تواريخ التوزيعات القادمة.
- **🔎 مستكشف الأسهم** — جدول بيانات (TanStack Table) قابل للفرز والتصفية حسب السوق والتصنيف والقطاع، مع اختيار الأعمدة، بعرض موحّد أو مجمّع قطاعياً.
- **⌨️ بحث سريع** — `Ctrl/⌘+K` أو `/` للانتقال إلى أي سهم أو صفحة، بمطابقة عربية تتسامح مع الهمزات والتاء المربوطة.
- **📉 مخططات الأسعار** — Lightweight Charts بأسعار إغلاق حقيقية فقط (أسهم دبي)، ومخطط TradingView المتقدم عند الطلب.
- **💵 التوزيعات** — تقويم تواريخ الاستحقاق والدفع، مع تصدير المواعيد القادمة كملف تقويم `.ics` (Google / Apple / Outlook) بتنبيه قبل كل موعد بيوم.
- **📈 النتائج المالية** — مؤشرات الأداء وملخّصات الشركات.
- **⚖️ المقارنة** — مقارنة بصرية متعددة المحاور بين الأسهم.
- **💼 حاسبة المحفظة** — حساب الدخل السنوي/الشهري المتوقّع من التوزيعات، مستشار تنويع، محاكي إعادة استثمار الأرباح (DRIP)، أهداف حياتية مغطّاة بالأرباح، وتصدير تقرير PDF. تُحفظ المحفظة والهدف محلياً في المتصفح (`localStorage`).

## التقنيات

- **React 19** + **TypeScript** + **Vite 8** (Rolldown) + **React Compiler 1.0** (تحسين إعادة الرسم تلقائيًا وقت البناء)
- **TanStack Router** — روابط قابلة للمشاركة لكل صفحة وسهم وفلتر (سجل بالهاش يناسب GitHub Pages)
- **TanStack Query** لجلب البيانات وتخزينها مؤقتًا، و**Zustand** لحالة المحفظة (بمفاتيح التخزين القديمة نفسها)
- **Zod 4 Mini** — عقد بيانات واحد يُشتق منه نوع TypeScript ويُتحقق به وقت التشغيل وفي CI
- **Recharts** للرسوم الإحصائية، و**Lightweight Charts** لمخططات الأسعار، و**cmdk** للبحث السريع
- **Tailwind CSS 4** + متغيّرات CSS (دعم الوضعين الفاتح والداكن)
- **Lucide** للأيقونات، وخط **IBM Plex Sans Arabic** مستضاف ذاتيًا (أرقام متساوية العرض تصطف في الجداول)

## التشغيل محلياً

```bash
npm install
npm run dev        # خادم تطوير على http://localhost:5173
```

## الروابط

| الرابط | ما يفتحه |
|--------|----------|
| `#/screener?ex=ADX&cat=income` | المستكشف مفلترًا (سوق أبوظبي، دخل مستقر) |
| `#/screener?q=بنك&sort=yield` | بحث مع ترتيب حسب العائد |
| `#/dividends?stock=EMAAR` | بطاقة إعمار فوق صفحة التوزيعات (`?stock=` يعمل على أي صفحة) |
| `#/financials?sym=FAB&tab=governance` | نتائج بنك أبوظبي الأول — تبويب الإفصاحات |

## إمكانية الوصول

يُفحص الموقع بـ axe-core وفق WCAG 2.1 (A/AA) في السمتين الفاتحة والداكنة بلا مخالفات: تباين ألوان ≥ 4.5:1،
تسميات لكل الحقول، رابط «تخطَّ إلى المحتوى»، عناوين فرز وروابط تعمل من لوحة المفاتيح، وحبس التركيز في النوافذ مع
إعادته لعنصر الفتح عند الإغلاق.

## مصدر البيانات

يجلب `scripts/update-data.mjs` يوميًا أسعار الأسهم وقراءة المؤشرين العامّين (حقل `indices` في الملف)؛ وعند تعذّر جلب
المؤشرين تبقى آخر قراءة محفوظة بتاريخها، أو تعرض الواجهة حالة «غير متوفر» صريحة بدل أرقام ثابتة.

تُحمّل البيانات وقت التشغيل من `public/data.json`؛ وفي حال تعذّر ذلك يُعتمد على نسخة احتياطية
مُضمّنة في `src/data/seed.json`. شكل البيانات معرّف مرة واحدة في `src/data/schema.ts` (عقد البيانات)،
وتُشتق منه الأنواع في `src/data/index.ts`. يرفض التحديث اليومي دفع أي ملف يخالف العقد، ويفحص
`ci.yml` كل فرع وطلب دمج (الأنواع، جودة الكود، الاختبارات، البناء).

## بنية المشروع

منظّمة حسب الميزات (feature-based) مع `@/` كاختصار لمجلد `src`:

```
src/
├── main.tsx · App.tsx · App.css   نقطة الدخول والهيكل العام (Outlet + بطاقة السهم من ?stock=)
├── router.ts · pages.tsx · search.ts   المسارات، مكوّنات الصفحات، والتحقق من معاملات الرابط
├── features/           كل صفحة في مجلدها المستقل مع مكوّناتها
│   ├── overview/       Overview + MarketIndexCards + LiveActionsFeed + overview.css
│   ├── screener/ · dividends/ · compare/
│   ├── financials/     Financials + tradingSim (محاكيات بيانات التداول)
│   └── portfolio/      Portfolio + PortfolioIntel
├── components/         مكوّنات مشتركة: Sidebar · StockDetail · Avatar · Snowflake · ui/
├── store/              queries (TanStack Query) · portfolioStore (Zustand) · useStocks · usePortfolio · useMarketStats
├── data/              schema (عقد Zod) · index (الأنواع) · seed.json · movements · logos · sectors
├── constants/          ثوابت الواجهة (NA · PALETTE · TIP_STYLE)
├── market.ts           أدوات بيانات السوق المحاكاة (مشتركة)
├── lib.ts · format.ts  منطق نقي: التواريخ/التنبيهات وتحليل الأرقام العربية
└── index.css           الأنماط العامة ومتغيّرات السمة
```
